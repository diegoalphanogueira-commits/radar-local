# Radar Maps Collector 1.2.3

Esta versão adiciona sincronização em tempo real com o Radar Local.

## Instalação
1. Baixe o ZIP da branch `release/radar-maps-collector-v1.2.3`.
2. Extraia a pasta.
3. Abra `chrome://extensions`.
4. Ative **Modo do desenvolvedor**.
5. Clique em **Carregar sem compactação**.
6. Selecione a pasta que contém `manifest.json`.
7. Recarregue o Radar Local com `Ctrl + F5`.

Durante a coleta, o Radar mostra progresso, atualiza telefone/site conforme cada ficha termina e recupera o estado da extensão depois de um F5.
