# Instalação — Radar Maps Collector 1.4.4 RC15

1. Baixe a branch `release/radar-local-v1-rc15`.
2. Extraia o ZIP.
3. Abra `chrome://extensions`.
4. Ative o Modo do desenvolvedor.
5. Clique em **Carregar sem compactação**.
6. Selecione `chrome-extension/radar-maps-collector`.
7. Confirme a versão **1.4.4**.
8. Feche abas antigas do Google Maps deixadas por versões anteriores.
9. Volte ao Radar e use `Ctrl+F5`.
