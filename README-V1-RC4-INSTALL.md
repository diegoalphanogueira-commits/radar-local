# Instalação — Radar Local V1 RC4

1. Baixe o ZIP da branch `release/radar-local-v1-rc4`.
2. Extraia o arquivo.
3. Abra `chrome://extensions`.
4. Ative o modo desenvolvedor.
5. Clique em **Carregar sem compactação**.
6. Selecione `chrome-extension/radar-maps-collector`.
7. Confirme a versão **1.3.3**.
8. Volte ao Radar Local e pressione `Ctrl + F5`.

A RC4 pede acesso a páginas HTTP/HTTPS porque a Etapa 3B analisa os sites oficiais das empresas em segundo plano para localizar presença e contatos públicos.
