# Instalação rápida — Radar Maps Collector 1.2.2

1. Extraia o ZIP.
2. Abra `chrome://extensions`.
3. Ative o Modo do desenvolvedor.
4. Remova/desative a versão anterior do Radar Maps Collector.
5. Clique em **Carregar sem compactação**.
6. Selecione a pasta que contém `manifest.json`.
7. Reabra o Radar Local e faça `Ctrl + F5`.
8. Confirme que o Radar mostra **Extensão 1.2.2**.

Teste recomendado: `Petshop` + `Jardim Presidente Dutra` + raio `5 km`.
