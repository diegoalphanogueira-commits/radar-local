# Instalação RC14

1. Baixe a branch `release/radar-local-v1-rc14` em ZIP.
2. Extraia o ZIP.
3. No Chrome, abra `chrome://extensions`.
4. Ative o modo do desenvolvedor.
5. Remova ou desative a versão anterior do Radar Maps Collector.
6. Clique em `Carregar sem compactação`.
7. Selecione a pasta `chrome-extension/radar-maps-collector`.
8. Confirme que a extensão mostra a versão `1.4.3`.
9. Volte ao Radar Local e faça `Ctrl + F5`.

Teste sugerido:
- segmento: Dentista
- região: Campo Limpo Paulista, São Paulo
- raio: 5 km
- cobertura: Máxima

Durante a descoberta, as abas abrem e fecham uma por vez. Os resultados parciais devem aparecer no Radar antes do fim. Quando a descoberta terminar, começa a fase de enriquecimento com até 3 abas paralelas.
