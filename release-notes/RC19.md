# Radar Local V1 RC19 — 1.4.8

Mudança principal: a descoberta passa a usar uma única busca principal no Google Maps.

- Se o usuário pesquisar `dentista`, o Radar abre uma única aba `dentista` centralizada na região solicitada.
- Essa mesma aba rola continuamente até o fim da lista ou estabilização real do feed.
- Não abre buscas paralelas de odontologia, clínica odontológica etc. durante a descoberta.
- O progresso é atualizado durante a rolagem conforme empresas únicas aparecem.
- Depois que a lista principal termina, inicia o enriquecimento das fichas em até 3 abas paralelas para telefone, site e horário.
- Cache de cobertura separado por termo exato + região + raio para evitar mistura entre pesquisas diferentes.
